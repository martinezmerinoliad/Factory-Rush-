# 🏭 Factory Rush

**Factory Rush** es un juego interactivo de planificación de producción creado como parte de un proyecto de pasantía industrial.

## 🎮 ¿Cómo se juega?

Sos el **Production Manager**. Cada pedido debe avanzar por:

**Corte láser → Plegado → Soldadura → Limpieza → Pintura en polvo → Horno → Despacho**

1. Seleccioná un pedido.
2. Asignalo a una máquina compatible que esté libre.
3. Cuando termine una etapa, mandalo a la siguiente.
4. Prestá atención a prioridades y plazos.
5. Reaccioná a las alertas antes de que termine el contador.
6. Intentá completar todos los pedidos a tiempo y controlando los costos.

## 🎲 Cada partida es diferente

Los pedidos cambian en cantidad de piezas, prioridad y plazo. Los imprevistos también se seleccionan aleatoriamente y aparecen en distintos momentos, por lo que no existe una secuencia única para ganar.

## 🏆 Puntaje

El resultado considera pedidos completados, entregas a tiempo, costos y decisiones tomadas frente a imprevistos.

## 💡 Objetivo

Representar de manera interactiva conceptos como planificación de producción, asignación de recursos, dependencia entre procesos, prioridades y toma de decisiones.

## ⚠️ Importante

Esta es una **simulación educativa**. Los tiempos, costos, capacidades, pedidos y eventos son **ficticios** y fueron creados exclusivamente para el juego. No representan datos reales ni información interna de ninguna empresa.
